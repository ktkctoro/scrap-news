AIのためのフォルダ設計　第5回（最終回）

日誌と保険があれば、思いきって頼める

ここまでで、部屋・置き場所・棚・張り紙がそろいました。最後は失敗しても困らないしくみです。これがあると、AIに大きな仕事も安心して頼めるようになります。

1日誌には「なぜそうしたか」を残す

日誌に書くことscrap-news の引き継ぎ書での場所
作った順番と、きっかけ§3 作った順番
ハマったところ（地雷）§4
測った結果§8
次にやること§6
やらないと決めたこと§6 の中

いちばん見落としやすいのは「やらないと決めたこと」です。書いていないと、次のAIが親切心で、前に断った提案をまたしてきます。

2こまめにセーブ（コミット）する

git の「コミット」は、ゲームのセーブと同じです。AIが部屋をめちゃくちゃにしても、セーブがあれば、その地点から始め直せます。

だから、大きな変更を頼む前に、まずセーブしておきます。

頼み方

ここまでの変更をコミットしてください。
さっきのコミットの状態まで戻してください。戻す前に、何が消えるか教えてください。

Claude Code では、Esc を2回押すと会話の少し前に巻き戻すこともできます。ただし戻せるのは、AIが書きかえたファイルが中心です。いちばん確かな保険はコミットです。

3別の線路で試す（枝＝ブランチ）

本番に影響を出さずに試したいときは、本番の線路から分かれた「試しの線路」を作ります。これを git では「枝（ブランチ）」と呼びます。

今回のやりとりが、まさにその例です。張り紙の直しも学習ページも、全部 claude/agents-md という試しの線路に入っています。そのあいだも、本番（main）では毎朝の自動更新がいつもどおり走っていました。

うまくいったら本番に合流させます。だめなら線路ごと外せば、本番は無傷です。「まだ main に入れていません」と毎回お伝えしていたのは、このためです。

4セーブは別の場所の倉庫にも預ける（プッシュ）

パソコンの中のセーブだけだと、パソコンが壊れたら全部なくなります。プッシュは、セーブを GitHub という別の場所の倉庫に預けることです。今回の作業も、毎回プッシュしてから終わっていました。

5セーブに入れない物のリスト（.gitignore）

何度でも作り直せる物や、合い鍵は、セーブに入れません。その一覧を書いておく紙が .gitignore です。第3回の棚でいうと、③できあがり品の一部と、⑥金庫に当たります。

入れない物の例携帯用.html（いつでも作り直せる）、パスワードや鍵
入れる物の例history.json（貯金箱。なくすと戻らない）

取り返しがつかない頼みごとに注意

次のような頼みごとは、セーブごと消えてしまうことがあります。

  • 「全部消して作り直して」
  • 「強制的に上書きして（force push）」

こういうときは、最後にこの一言を付け足してください。

やる前に、何が消えるか・元に戻せるかを教えてください。私が「はい」と言うまで実行しないでください。

6覚えておく言葉

コミットセーブすること
ブランチ（枝）本番から分かれた試しの線路
プッシュセーブを GitHub の倉庫に預けること
main本番の線路の名前

第5回のまとめ

  1. 日誌には「なぜ」と「やらないと決めたこと」を残す
  2. 大きな変更の前に、まずセーブ（コミット）
  3. 試すときは別の線路（ブランチ）で。本番は止めない
  4. セーブは GitHub の倉庫に預ける（プッシュ）
  5. 取り返しがつかない頼みごとには「やる前に教えて」を付ける

たしかめクイズ

考えてから押してください。

Q1AIに画面を大きく作りかえてもらう。頼む前にすることは？
セーブ（コミット）しておく。うまくいかなかったら、そのセーブまで戻せます。
Q2新しい画面を試したい。でも毎朝の自動更新は止めたくない。どうする？
試しの線路（ブランチ）を作って、そこで試す。本番（main）はそのまま走り続けます。うまくいったら合流させます。
Q3「Bingはやめよう」と3か月前に決めた。どこに書いておく？
日誌（引き継ぎ書）の「やらないと決めたこと」。理由もいっしょに書いておけば、次のAIが同じ提案をくり返しません。（※たとえ話です。scrap-news では今も Bing を使っています）

全5回のふりかえり

  • 1AIの仕事部屋AIは開けたフォルダ（部屋）の中しか見ない
  • 2AIの階をつくるAIの部屋は ai-work に集める。ルールの紙は大・中・小
  • 3部屋の棚の分け方ファイルは6つの棚に分けて、さわってよい物を決める
  • 4張り紙の書き方張り紙は初出勤のAIへの引き継ぎメモ。理由をそえて短く
  • 5日誌と保険日誌に「なぜ」を残し、セーブと試しの線路で失敗に備える

この5つがそろうと、AIは毎回「初日の新人さん」でも、部屋に入ってすぐ、決まりを守って働けます。そして失敗しても元に戻せるので、あなたは安心して大きな仕事を頼めます。これが「AIを使い倒す」ための土台です。
