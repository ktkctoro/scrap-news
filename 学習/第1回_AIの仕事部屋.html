AIのためのフォルダ設計　第1回

AIは「開けた部屋」の中しか見ない

Claude Code や Codex に仕事を頼むとき、最初にかならず「フォルダ」を開きます。じつはどのフォルダを開くかで、AIの仕事の出来が大きく変わります。今回はそのわけを、家と部屋にたとえて説明します。

1パソコンは「家」、フォルダは「部屋」

家 ＝ パソコン 部屋 ＝ フォルダ ロボット ＝ AI（Claude Code・Codex）

AIは、あなたが開けた1つの部屋の中だけで働きます。

その部屋の中にある物は、読んだり書き直したりします。ほかの部屋は暗くて見えないので、基本的にさわりません。

2部屋の選び方で、こんなに変わる

同じAIに同じ仕事を頼んでも、どの部屋に入れるかで結果がちがいます。3つの場合をくらべてみます。

広すぎ

デスクトップ全体を開いた

関係ない物まで目に入って、AIが迷います。さわってほしくない「大事な書類」にも手が届いてしまいます。

ちょうどいい

scrap-news を開いた

この仕事の物だけがそろっています。壁の「ルールの紙」も読めるので、決まりを守って作業できます。

せますぎ

scrap-news の中の「画面案」だけを開いた

せまい押し入れに入れられた状態です。外の壁にある「ルールの紙」も、データを集める仕組みも見えません。何も知らないまま作業してしまいます。

3部屋の「張り紙」は、AIの記憶の代わり

AIには、もう1つ大事なクセがあります。AIは、前の日に話したことを覚えていません。毎回、初めてその部屋に入る人と同じです。

そこで役に立つのが、部屋の入口に張っておく「ルールの紙」です。AIは部屋に入ると、まずこの紙を読みます。

scrap-news の部屋には、AGENTS.md（Codex が読む紙）と CLAUDE.md（Claude Code が読む紙）が張ってあります。「説明は日本語で」「お金のかかるものは足さない」といった決まりが書いてあります。

ここで大事なのは、AIが読むのは「開けた部屋」の張り紙だということです。部屋をまちがえると、別の仕事の決まりを読んでしまいます。

4本当にあった失敗

前に、動画の仕事（vlog-maker）の部屋を開いたまま、となりの scrap-news の物をさわっていたことがありました。

するとAIは、動画の部屋の張り紙を読んで、その決まりのまま scrap-news の作業をしてしまいました。ニュースの部屋の張り紙は、一度も読まれていませんでした。

それからは「かならず scrap-news の部屋を開いてから始める」と決めています（引き継ぎ書.md の §0 に書いてあります）。

5正しい部屋の開け方

Claude のアプリから開くとき

  1. 新しく始めるときに「フォルダを選ぶ」画面が出ます
  2. scrap-news フォルダを選びます（デスクトップや、その中の 画面案 ではなく）

黒い画面（PowerShell）から開くとき

1行ずつ貼りつけて Enter を押します。

cd "$env:USERPROFILE\scrap-news"
claude

Codex を使うときは、2行目の claude を codex に変えます。1行目の「部屋に入る」ところは同じです。

第1回のまとめ

  1. AIは、開けたフォルダ（部屋）の中だけで働く
  2. 広すぎると迷い、せますぎると何も知らないまま作業する
  3. AIは前の日のことを忘れる。部屋の「ルールの紙」が記憶の代わり
  4. だから、いつも「その仕事の部屋」をまるごと開いてから頼む

たしかめクイズ

問題を押すと答えが出ます。

Q1経理の表をAIに直してもらいたい。開くのはどれ？　ア：デスクトップ全体　イ：経理のフォルダ　ウ：scrap-news
イ：経理のフォルダ。その仕事の部屋だけを開きます。ア は広すぎ、ウ は別の仕事の部屋です。
Q2scrap-news の中の「画面案」フォルダだけを開いて「画面を作り直して」と頼んだ。何が困る？
部屋の外にある ルールの紙（AGENTS.md）や、データを集める仕組みが見えないことです。決まりを知らないまま作り直してしまいます。scrap-news をまるごと開いてから「画面案を見て」と頼みます。
Q3AIは、きのう話したことを覚えている？
覚えていません。だから、覚えておいてほしいことは部屋の「ルールの紙」や 引き継ぎ書.md に書いておきます。
