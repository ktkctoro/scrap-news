# スクラップ今日 — 設置手順

朝いちに、自分の商売に効くニュースだけを1分で見るための小さな仕組みです。
Python の標準機能だけで動くので、追加のインストールは要りません。

## ファイル

| ファイル | 役割 |
|---|---|
| `collect.py` | ニュースと為替をあつめて `data.json` を作る |
| `manual.json` | 建値・金・銀を手で書くところ |
| `index.html` | スマホで見る画面 |
| `data.json` | 上の結果。自動で作られる |

## 動かす

Windows のコマンドプロンプトで、このフォルダに入って:

```
python collect.py
python -m http.server 8000
```

同じ Wi-Fi のスマホから `http://（PCのIPアドレス）:8000/` を開きます。
Safari なら共有ボタン →「ホーム画面に追加」でアイコンになります。

`index.html` をダブルクリックで直接開くと、ブラウザの制限で `data.json` を
読めません。必ず上の `http.server` 経由で開いてください。

## 毎朝これを自動でやる

Windows の「タスクスケジューラ」で、毎朝5時に `python collect.py` を実行する
タスクを1つ作れば、起きたときには最新になっています。

## 直したくなったら

- 拾うキーワードを増やす → `collect.py` の `QUERIES`
- 分類のされ方を変える → `collect.py` の `CLASSIFY`
- AI・DCのノイズを減らす → `collect.py` の `DC_MUST_HAVE`
- 建値・金・銀の数字 → `manual.json`

## 承知しておくこと

- Googleニュースの無料フィードは、リンクが Google 経由の転送になります。
  また新着がすぐには載らないことがあり、当日の記事が少ない日もあります。
- 建値・金・銀は、無料で自動取得できる先がありません。当面は `manual.json` を
  手で書き換える形にしています。毎朝の数字が決まった画面から取れるなら、
  そこを読みにいく処理を後から足せます。
- 為替は欧州中央銀行の公表値（Frankfurter）を使っています。1日1回の更新なので、
  日中の値動きは追えません。
